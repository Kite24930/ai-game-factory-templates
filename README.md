# AIゲームファクトリー：ゲームのテンプレート

2026年10月3日の親子向けAIゲームづくりで使う、3種類の完成形テンプレートです。

| ゲーム | ファイル |
|---|---|
| 横スクロール2Dアクション | [templates/action.html](templates/action.html) |
| レーシング | [templates/racing.html](templates/racing.html) |
| 戦闘中心のRPG | [templates/rpg.html](templates/rpg.html) |

各ファイルには画像とゲームエンジンを内包しています。制作例の見た目・音・ゲーム性を残したまま、自分の主人公、マシン、世界、ルールへ作り変える土台です。HTMLだけで実行でき、遊ぶ人の環境にNode.jsの導入は不要です。

## Geminiで使うとき

ファイルの本文を取得できるRaw URLを、特設ページの開始用プロンプトに含めます。GitHubへの公開や通常のHTTPでの取得成功は、Geminiが全文を読み、画像やゲームエンジンを保ったままCanvasで編集できることの保証ではありません。

元の画像・ゲームエンジンを省略して小さな別ゲームに置き換えず、変更したい部分を直してから実際に遊んで確認してください。読み取りができなかった場合は、読めたことにして制作を進めないでください。

テンプレートの初期状態は採用済みの制作例と同じ完成形です。参加者全員のキャラクター・世界観・ルールを固定するものではありません。

## 操作

- アクション：← → で移動、スペースでジャンプ。空中で2回目のジャンプ。
- レーシング：← → でハンドル、スペースでアクセル、離すとブレーキ、Zでアイテム。
- RPG：矢印キーで移動。戦闘は技をクリック、または矢印で選びスペース。

## サイズとライブラリー

- アクション：約7.4MiB、Phaser。
- レーシング：約4.4MiB、Three.js。
