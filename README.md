## 資料の役割

- HTML：画像・ゲームエンジンを内包した、実際に遊べる見本。見栄え、操作感、ゲーム性の品質を確認します。
- GUIDE.md：参加者の希望から新しいゲームを作る考え方、見本の仕組み、試遊で確認する点。
- SOURCE.md：画像のbase64とライブラリー本体を除いたアプリ側ソースを集約。設定、描画、入力、音、ゲームのルールを読む技術資料。設定値も収録しています。
- settings.sample.json：見本の設定値。変更可能な項目や数値の上限を参加者に課すものではありません。

制作例と同じ世界、敵、ステージ数、アイテム、画像を残すことは必須ではありません。便利なコードや素材を再利用してもよく、すべてをゼロから書き直す必要もありません。参加者のアイデアに合わせて構成や仕組みを変えつつ、見本で確認できる品質を目指します。小学生が作ることを、品質を下げる理由にしません。

既存URLのため `templates/` とリポジトリ名は維持しています。その名前によって「完成したゲームの絵だけを差し替える」運用を指定するものではありません。

## Geminiで使うとき

特設ページの開始用コピー文に、そのジャンルの作り方の参考・読みやすいコード・制作例のRaw URLをまとめます。参加者は開始文を1回コピーし、その後は同じGeminiの会話で考える・遊ぶ・直すを進めます。資料の個別ダウンロードやNode.jsの導入は通常の参加者手順に含めません。

技術資料は完成HTMLより軽量ですが、SOURCE.md自体は実行ファイルではありません。画像・エンジンを含む見本の実行にはHTMLを使います。新しいCanvasゲームは、使える画像とライブラリーの読み込み方法を確認して構成してください。参照できない画像や未取得のファイルを、読み込めたことにしてはいけません。

公開・通常HTTPでの取得成功は、Geminiが資料を読めることやCanvasで制作できることの保証ではありません。新しいゲームを作り、主人公画像の反映、試遊、修正、共有まで確認する検証は別に必要です。

## 見本の操作

- アクション：← → で移動、スペースでジャンプ。空中で2回目のジャンプ。
- レーシング：← → でハンドル、スペースでアクセル、離すとブレーキ、Zでアイテム。
- RPG：矢印キーで移動。戦闘は技をクリック、または矢印で選びスペース。

## サイズとライブラリー

- アクション：約7.4MiB、Phaser。
- レーシング：約4.4MiB、Three.js。
- RPG：約18MiB、Phaser。

同梱ライブラリーのMITライセンスと著作権表示はHTML内に保持しています。再利用するライブラリーのライセンス表示を維持してください。アプリ側コード・画像に新しい包括ライセンスを付けたものではありません。このリポジトリには講演の内部資料、参加者データ、認証情報を含めません。
