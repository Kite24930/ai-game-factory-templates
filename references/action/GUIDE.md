# 横スクロール2Dアクションの作り方の参考

## 今回作るもの

参加者が考えた主人公、世界、遊び方で、新しい横スクロール2Dアクションを作ります。左右に進み、足場を渡るマリオやカービィのような方向性です。奥へ進むゲームとして扱わないでください。

「月灯りの庭」は品質と実装の参考例です。キツネ、夜の庭、月のかけら、2回ジャンプなどを全員に指定するものではありません。便利なコードや素材は再利用できます。参加者の能力・敵・仕掛けのアイデアも反映できます。

## 資料

- [SOURCE.md](SOURCE.md)：設定、シーン、入力、音、見た目、画像の切り出し情報をまとめた参考コード。設定値も入っています。
- [settings.sample.json](settings.sample.json)：見本の設定例。変更可能な項目や数値の上限を参加者に課すものではありません。
- [action.html](../../templates/action.html)：画像とPhaserを含み、そのまま遊べる見本。

## 見本から参考にできる仕組み

- `game.js` の `Garden`：足場・敵・集めるもの・主人公を作り、毎フレーム入力と状態を更新。カメラは横方向に主人公を追います。
- `update`：上限付きの時間差で加速・減速・ジャンプ・足場・接触判定を処理。ジャンプ先行入力と足場を離れた直後の猶予が、操作の気持ちよさを支えます。
- `renderHero`：当たり判定の体と見せる絵を分け、移動・ジャンプ・着地で姿や影を変えます。1枚の主人公画像も使えます。
- `failRun` / `finish`：失敗後の再挑戦とゴール演出。集めたものを維持する仕組みも参考になります。
- `input.js`：押した瞬間と押し続けを区別。画面から離れた際に入力をリセット。
- `audio.js` / `style.css`：音と画面の演出。音は操作後に開始し、止める方法も用意します。

この一覧は全機能を保持する義務ではありません。新しい能力を入れる場合は、設定変更だけに限定せず、ルール・描画・操作を合わせて変えられます。見本の検証関数の制約は、新しいゲームの許される範囲ではありません。

## 品質の確認

- 主人公、足場、敵が見分けやすく、進む方向や目的がわかる。
- 入力したことがすぐ動きや音で返り、絵と当たり判定が納得できる。
- 単に歩くだけではなく、ジャンプや仕掛けへの判断が楽しさにつながる。
- 届かない足場や詰まって動けない場所がなく、失敗後に再挑戦できる。
- 背景・色・主人公・演出が、その参加者の世界観に合う。理由なく粗い図形だけへ品質を落とさない。

## 制作の進め方

主人公の希望を聞いて絵を作り、次に世界や遊び方を一つ聞きます。全部の設定やタイトルが決まるまで待たず、短い希望から遊べるCanvasを作ります。未指定部分は見本をヒントに補えますが、見本と同内容に固定せず、後から自由に変えられるようにします。

素材・ライブラリーの読み込みを確かめ、実際に遊べる画面と短い操作案内を出します。資料が読めない場合は読めたと言わず、子どもにコード調査や繰り返しの作業を求めず先生へ相談する案内をします。資料の個別ダウンロードやローカルビルドは通常の参加者手順に含めません。できた後は本人が遊び、本人の希望で直します。
